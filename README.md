## 📌 프로젝트 소개

> 뜨개질 관련 정보(카페 허용 여부, 도안 공유 등)가 인스타그램 등 일반 SNS에 산재해 있어
뜨개인 특화 플랫폼의 필요성을 느껴 기획한 React 개인 프로젝트입니다.

> **뜨개질 가능한 카페를 지도로 찾고, 도안을 공유하고, 뜨개인들과 소통할 수 있는 커뮤니티 플랫폼**이에요.

<br>

## 🛠 사용 기술

**Frontend**
- React 18, Vite
- React Router v6
- CSS Modules
- MUI (Material UI)
- framer-motion

**Backend**
- Node.js, Express
- JWT, bcrypt

**Database**
- Oracle Database 21c XE
- node-oracledb

**라이브러리**
- Multer (이미지 업로드)
- Sharp (이미지 리사이징)
- Socket.io (실시간 채팅)
- jwt-decode

**API**
- 카카오맵 API

**버전 관리**
- Git, GitHub

<br>

## ✨ 주요 기능

### 🗺 뜨개 지도
- 카카오맵 API 연동, 카페 마커 표시
- 허용/금지/모르겠어요 상태별 색상 구분
- 장소 검색 및 필터 기능
- 리뷰 작성 기능

### 🧵 도안 공유
- 도안 목록 (코바늘/대바늘 탭, 난이도/태그 필터)
- 멀티 이미지 업로드 (Sharp 리사이징)
- 좋아요 / 스크랩 / 댓글·대댓글

### 📋 커뮤니티 피드
- 트위터식 SNS 피드 (자유/질문/모여떠요/떠주세요/떠드려요)
- 인라인 게시글 작성 (이미지 최대 3장)
- 팔로잉 피드 탭 (내가 팔로우한 사람 게시글만)
- 좋아요 / 스크랩 / 댓글·대댓글

### 👤 유저 페이지 & 소셜
- 팔로우/팔로잉, 맞팔로우 뱃지
- 내 도안 / 게시글 / 스크랩 탭
- 활동 통계 위젯
- 1:1 DM 채팅

### 💬 채팅
- 모여떠요 게시글 연동 그룹 채팅방
- 1:1 DM 채팅방
- 실시간 메시지 (폴링 방식)
- 미읽음 뱃지

### 🔔 알림
- 댓글 / 좋아요 / 팔로우 / 채팅 알림 자동 생성
- 읽음 처리, 미읽음 뱃지

### 🔐 계정 관리
- 회원가입 / 로그인 (JWT)
- 아이디 찾기 / 비밀번호 찾기
- 비밀번호 변경 / 회원탈퇴
